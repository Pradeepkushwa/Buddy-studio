1. ⚡ Docker Setup — RECOMMENDED

Docker matlab ek box jisme sab kuch already installed hai — Python, Node, Ruby, sab. Tumhe kuch install nahi karna.

Step 1 — Docker Desktop install karo (ek baar)

Download: https://www.docker.com/products/docker-desktop/

Mac pe install karo, phir Docker Desktop open karo (whale icon dikhega menu bar mein).

Step 2 — Repository clone karo

git clone https://github.com/Pradeepkushwa/Buddy-studio
cd Buddy-studio

Step 3 — .env file setup

make setup

Ye command .env.docker file banayega. Phir isse open karo aur sirf 2 cheezein bharo:

GEMINI_API_KEY=your_gemini_api_key_here   ← yahan apni key daalo
SUPPORT_PHONE=+91-XXXXXXXXXX              ← real phone number daalo
⚠️ .env.docker kabhi bhi git mein commit mat karo — .gitignore mein add hai.

Step 4 — Sab kuch start karo

make start

Pehli baar 5-10 minute lagenge (images download hoti hain). Uske baad:

✅ React Frontend: http://localhost:3000
✅ Rails API: http://localhost:3001
✅ Python Agent: http://localhost:8000
✅ Agent Docs: http://localhost:8000/docs

Daily use (next time)

make start    # start
make stop     # stop
make logs     # live logs dekhne ke liye

Code change kiya?

make build    # rebuild karo phir make start

3. Manual Setup — Prerequisites (Docker nahi use karna to)

Check what you already have

python3 --version    # Need 3.10+
node --version       # Need 18+
ruby --version       # Need 3.x
rails --version
git --version

Install Homebrew (Mac — if not installed)

/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

Install Node.js (for React)

brew install node

Install Ruby + Rails (if not installed)

brew install rbenv ruby-build
rbenv install 3.2.0
rbenv global 3.2.0
gem install rails bundler

Install PostgreSQL (for Rails database)

brew install postgresql@14
brew services start postgresql@14

4. Python Buddy Agent (FastAPI) — Manual

Folder: Buddy-studio/buddy-agent/ | Runs on: http://localhost:8000

Step 1 — Go to the folder

cd ~/Pradeep/Buddy-studio/buddy-agent

Step 2 — Create Virtual Environment (venv)

⚠️ Always create venv inside the buddy-agent folder. Do this only ONCE.
python3 -m venv venv

This creates a venv/ folder — it's like a private Python workspace for this project.

Step 3 — Activate venv

⚠️ You must activate venv EVERY TIME you open a new terminal window.
source venv/bin/activate

After activation you'll see (venv) at the start of your terminal line like:

(venv) buddy-agent $

Step 4 — Install packages

pip install -r requirements.txt

Do this once, or whenever requirements.txt changes.

Step 5 — Create .env file

cp .env.example .env

Then open .env and fill in your values:

LLM_PROVIDER=gemini
GEMINI_API_KEY=your_gemini_api_key_here
GEMINI_MODEL=gemini-1.5-flash
SUPPORT_PHONE=+91-XXXXXXXXXX
SUPPORT_WHATSAPP=+91-XXXXXXXXXX
ALLOWED_ORIGINS=http://localhost:3000

Step 6 — Start the server

uvicorn app.main:app --reload --port 8000

The --reload flag auto-restarts when you change code.

Step 7 — Test it's working

# In a new terminal:
curl http://localhost:8000/health

You should see a JSON response with "status": "ok"

✅ API docs available at: http://localhost:8000/docs (Swagger UI)

Deactivate venv (when done)

deactivate

Full flow — Copy paste this (after first setup)

cd ~/Pradeep/Buddy-studio/buddy-agent
source venv/bin/activate
uvicorn app.main:app --reload --port 8000

5. React Frontend — Manual

Folder: Buddy-studio/frontend/ | Runs on: http://localhost:3000

Step 1 — Go to the folder

cd ~/Pradeep/Buddy-studio/frontend

Step 2 — Install Node packages

⚠️ Do this ONCE (or when package.json changes)
npm install

This creates node_modules/ folder (can take 1-2 minutes).

Step 3 — Create .env file

cp .env.example .env

Fill in:

REACT_APP_API_URL=http://localhost:3001
REACT_APP_AGENT_URL=http://localhost:8000
REACT_APP_SUPPORT_PHONE=+91-XXXXXXXXXX

Step 4 — Start React

npm start

Browser will auto-open at http://localhost:3000

Build for production (optional)

npm run build
✅ React does NOT need venv. It uses node_modules/ instead.

6. Rails Backend API — Manual

Folder: Buddy-studio/backend/ | Runs on: http://localhost:3001

Step 1 — Go to the folder

cd ~/Pradeep/Buddy-studio/backend

Step 2 — Install Ruby gems

⚠️ Do this ONCE (or when Gemfile changes)
bundle install

Step 3 — Setup database

# Create the database
rails db:create

# Run migrations
rails db:migrate

# (Optional) Add sample data
rails db:seed

Step 4 — Create credentials / .env

cp .env.example .env   # if .env.example exists

Step 5 — Start Rails server

rails server -p 3001

Rails runs on port 3001 (so it doesn't conflict with React on 3000).

Test it's working

curl http://localhost:3001/health
# or
curl http://localhost:3001/api/v1/users
✅ Rails does NOT need venv. It uses Gemfile + bundler instead.

8. Running Tests

Python Tests (pytest)

cd ~/Pradeep/Buddy-studio/buddy-agent
source venv/bin/activate

# Run all tests
LLM_PROVIDER=none pytest tests/ -v

# Run a single test file
LLM_PROVIDER=none pytest tests/test_routes.py -v

# Run with output (print statements visible)
LLM_PROVIDER=none pytest tests/ -v -s
⚠️ Always use LLM_PROVIDER=none for tests — it skips real API calls

Rails Tests (RSpec)

cd ~/Pradeep/Buddy-studio/backend

# Run all tests
bundle exec rspec

# Run a specific file
bundle exec rspec spec/models/user_spec.rb

# Run with format
bundle exec rspec --format documentation

React Tests (Jest)

cd ~/Pradeep/Buddy-studio/frontend

# Run all tests
npm test

# Run once (no watch mode)
npm test -- --watchAll=false

# With coverage report
npm test -- --coverage --watchAll=false

9. Troubleshooting Common Errors

Python — "command not found: python"

python3 --version   # use python3, not python

Python — "pip: command not found"

# Make sure venv is activated!
source venv/bin/activate
pip --version   # should work now

Python — "ModuleNotFoundError"

source venv/bin/activate      # activate first
pip install -r requirements.txt   # then install

Python — venv is broken (after moving folder)

rm -rf venv                        # delete old venv
python3 -m venv venv               # create fresh
source venv/bin/activate
pip install -r requirements.txt

React — "npm: command not found"

brew install node
node --version    # check

React — Port 3000 already in use

PORT=3002 npm start   # use different port

React — "Module not found" after git pull

npm install    # someone added a new package

Rails — "could not connect to server" (database)

brew services start postgresql@14
rails db:create
rails db:migrate

Rails — Port 3001 already in use

lsof -i :3001          # find what's using it
kill -9 <PID>          # kill it
rails server -p 3001   # restart

Rails — "bundler: command not found"

gem install bundler
bundle install

General — Find what's running on a port

lsof -i :8000   # Python agent
lsof -i :3000   # React
lsof -i :3001   # Rails
