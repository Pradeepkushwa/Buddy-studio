Project Overview

BuddyStudio is a full-stack web application built for a professional photography studio based in Jhansi, Uttar Pradesh, India. The platform handles end-to-end studio operations including online bookings, appointment scheduling, team management, package management, gallery showcasing, customer reviews, revenue analytics, and in-app notifications — all from a single unified system.

Deployment Architecture

BuddyStudio is deployed on Render.com using their free tier services.

⚙️ Backend — Web Service

PlatformRender.com Web Service
RuntimeRuby 3.x
Build Commandbundle install
Start Commandrails db:migrate && rails db:seed && rails s
DatabasePostgreSQL (Render managed)
Root Directorybackend/

🖥️ Frontend — Static Site

PlatformRender.com Static Site
FrameworkReact (Create React App)
Build Commandnpm install && npm run build
Publish Dirbuild/
Root Directoryfrontend/
Env VariableREACT_APP_API_URL

Environment Variables Required

VariableServiceDescription
DATABASE_URLBackendPostgreSQL connection string from Render
SECRET_KEY_BASEBackendRails secret key (generate with rails secret)
SMTP_USERNAMEBackendGmail address for sending OTP emails
SMTP_PASSWORDBackendGmail App Password (not account password)
FRONTEND_URLBackendDeployed frontend URL for CORS
REACT_APP_API_URLFrontendDeployed backend API base URL

Deployment Steps

Step 1
Push code to GitHub
Ensure both frontend/ and backend/ directories are committed and pushed.
Step 2
Create PostgreSQL on Render
Create a new PostgreSQL database. Copy the Internal Database URL.
Step 3
Deploy Backend as Web Service
Connect GitHub repo, set root to backend/, add all environment variables.
Step 4
Deploy Frontend as Static Site
Set root to frontend/, set REACT_APP_API_URL to backend URL.
Step 5
Update CORS
Set FRONTEND_URL in backend to the deployed frontend URL for cross-origin requests.

Local Development Setup

Backend (Terminal 1)

cd backend
bundle install
rails db:migrate db:seed
rails s -p 3001

Runs at http://localhost:3001

Frontend (Terminal 2)

cd frontend
npm install
npm start

Runs at http://localhost:3000
